# NUMPA Competitor Watch

This is a research template, not a claim that a competitor currently has a specific feature or price.

## Record for each product
- Product and official URL
- Date checked
- Target audience and use case
- Supported formats and upload limits
- Profiling, cleaning, preview and undo
- Explainability and audit trail
- ML-readiness scoring and method, if documented
- Model evaluation and validation
- Privacy, retention and processing location
- Integrations and API
- Pricing, billing period, quotas and source URL
- Onboarding and time-to-value
- Evidence type: official source, observed demo or unverified
- NUMPA implication: gap, parity, differentiation or no action

## Comparison dimensions
| Dimension | Question |
|---|---|
| Time to value | How quickly can users inspect a dataset? |
| Trust | Can users understand and approve changes? |
| Auditability | Are operations and before/after metrics recorded? |
| Readiness | Is scoring task-aware and explainable? |
| Validation | Are leakage risks addressed? |
| Formats | Are limits and accepted inputs clear? |
| Privacy | Where is data processed and retained? |
| Export | Can users export data and reports? |
| Workflow | Can users reassess after cleaning? |
| Integration | Are APIs and automation documented? |

## Research rules
Use official product and pricing pages, record dates, distinguish marketing claims from tested behaviour, and do not copy proprietary assets or private information. Prioritize user value over feature-count parity.

Review monthly or before major product decisions.
