# NUMPA Research and Resource Library

Use docs/ for durable product and engineering specifications. Use resources/ for evidence, links and research that changes over time.

## Library
- OFFICIAL_TECH_REFERENCES.md — official documentation entry points.
- COMPETITOR_WATCH.md — dated competitor observations and sources.
- RESEARCH_BACKLOG.md — questions and experiments to resolve.

## Maintenance rules
1. Prefer official documentation, primary research and original product pages.
2. Record access dates for changing prices, quotas, features and API support.
3. Separate observed facts from interpretation and assumptions.
4. Cite sources for important claims; never fabricate citations.
5. Do not commit copyrighted books or paid-course content; record lawful bibliographic details and links instead.
6. Never store secrets, customer datasets or personal data here.
7. If research changes a product decision, update docs/ and record the decision in ARCHITECTURE_DECISIONS.md.
8. Review time-sensitive claims periodically and mark stale findings.
